About KNGames

KNGames is a library for discovering games published by the site owner. Some games may run in a browser on Windows PC, Android, or iPhone/iPad, depending on each game’s code and controls. Other games may require a separate Windows or Android download. Visitors can browse and play or download published games, but cannot upload games.

Only download game files you trust. Check that a downloaded file comes from the official game publisher before running it.
